# Local demonstration imagery and font

These locally bundled photographs illustrate the sample catalogue while no Invidious backend is configured. They are thematic stock/demo artwork, **not verified thumbnails for the sample YouTube videos**. Live-mode thumbnails are supplied by the configured Invidious backend. The chrome background is decorative artwork, not a video still.

The stock photographs in the table were downloaded unmodified from the public source repositories below. The generated chrome backdrop is described separately at the end of this file. Downloading did not disable TLS verification or tunnel any blocked host. No PokeTube screenshots, logos, application code, or original-site assets were copied.

## Chrome glass redesign

`chrome-background.png` is newly generated original decorative artwork created for this project: polished chrome torus rings and spheres on a graphite background. The application renders live text and controls over the image with CSS backdrop blur; the image contains no interface or embedded text. It replaces the former scenic hero photograph.
