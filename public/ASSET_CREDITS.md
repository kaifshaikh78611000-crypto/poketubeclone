# Local demonstration imagery and font

These locally bundled photographs illustrate the sample catalogue while no Invidious backend is configured. They are thematic stock/demo artwork, **not verified thumbnails for the sample YouTube videos**. Live-mode thumbnails are supplied by the configured Invidious backend. The hero is decorative artwork, not a still from the linked video.

All images were downloaded unmodified from the public source repositories below. Downloading did not disable TLS verification or tunnel any blocked host. No PokeTube screenshots, logos, application code, or original-site assets were copied.
